# Changelog — BHARAT: BEYOND THE STREETS

## v1.0.0 (in development)
- Initial project scaffold (Godot 4.7.2-stable)
- GameManager autoload: save/load, game state, offline-first
- Player controller: walk/run/sprint/jump/interact/enter-exit vehicle
- Vehicle system: RigidBody3D car physics, acceleration/steering/brake/reverse
- World system: procedural metro_city block, buildings, traffic AI
- UI: main menu (New Game/Continue/Exit) + HUD speed display
- Camera follow (player & vehicle)
- Input map: jump/sprint/interact/WASD
- Android SDK present at /opt/android-sdk
- GitHub repo: bharat-beyond-the-streets

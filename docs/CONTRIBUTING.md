# Contributing — BHARAT: BEYOND THE STREETS

## Guidelines
- All systems modular, testable, maintainable (see docs/GAME_ARCHITECTURE.md).
- Original content only — no copyrighted game maps/characters/story/branding.
- Verify licenses before integrating any third-party asset.
- Offline-first: core gameplay must not require internet.
- Android performance: measure, don't guess.

## Workflow
1. Create branch from main.
2. Implement + test system.
3. Update docs + ROADMAP.md + PROGRESS.md.
4. Open pull request; review; merge.

# BHARAT: BEYOND THE STREETS

Original Indian open-world 3D city life simulation for Android.

Engine: Godot 4.7.2-stable (MIT)
Platform: Android (primary), PC development/testing (secondary)
Genre: 3D Open World / Indian City Life Simulation / Adventure / Driving

About
BHARAT: BEYOND THE STREETS is a complete, original, offline-first Indian open-world 3D game for Android. It features a fictional India-inspired world with metro city, old city, rural, desert, mountain, coastal, forest, and festival regions; working vehicles; traffic AI; NPCs; story missions; festivals; day/night cycle; weather; save/load; and mobile touch controls.

No GTA maps, characters, story, branding, or ripped assets. All original.

Features
- Original Indian open-world map with 8 regions
- Playable character (walk, run, sprint, jump, interact)
- Working vehicle system (enter/exit, driving physics)
- Traffic AI + NPC system
- Story campaign + mission system
- Indian festivals & culture
- Day/night cycle + weather
- Shops, economy, inventory
- Mini-games (cricket, racing, photography, festival)
- Map + navigation
- Save/load (offline-first)
- Mobile-first UI (touch controls)
- Android APK/AAB build pipeline

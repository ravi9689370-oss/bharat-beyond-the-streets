# BHARAT: BEYOND THE STREETS — Development Roadmap

## Release Scope (v1.0)
An original, offline-first Indian open-world 3D game for Android. All systems implemented, integrated, and packaged as APK/AAB.

## Phases
| Phase | Focus | Status |
|-------|-------|--------|
| P0 | Environment setup, engine verification, project scaffold | Complete |
| P1 | Core systems: player controller, physics, camera, input | In Progress |
| P2 | World: Region 1 (Metro City) + streaming, terrain, roads | Planned |
| P3 | Vehicle system (working, enter/exit, handling) | Planned |
| P4 | Traffic AI + NPC system (schedules, navigation) | Planned |
| P5 | Story campaign + mission system | Planned |
| P6 | Indian culture & festivals system | Planned |
| P7 | Day/night + weather + ambience | Planned |
| P8 | Buildings/interiors + shops + economy + inventory | Planned |

| P11 | Audio (original soundtrack, ambience, mixer) | Planned |
| P12 | Save/load system (slots, autosave, validation) | Planned |
| P13 | Android performance optimization (LOD, culling, presets) | Planned |
| P14 | Testing, QA, bug fixes, regression | Planned |
| P15 | Android build (APK/AAB), CI pipeline, release | Planned |
